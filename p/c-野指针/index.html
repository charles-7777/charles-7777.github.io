什么是野指针

指向一块无效内存、或指向已不再归你使用的内存的指针，且程序无法察觉这一点。

关键在于"无法察觉"。NULL 不是野指针——对 NULL 解引用会立刻段错误，这是响亮的失败；野指针是沉默的失败：它可能指向已释放的堆、指向从未初始化的栈槽、指向已经退出的函数的栈帧……解引用它时程序不报错，只是悄悄地读写了不该碰的内存。

三者对比：

指针状态 解引用后果 可检测性
NULL 立刻 SIGSEGV 极易定位
野指针 可能正常、可能踩内存、可能崩溃 难
有效指针 符合预期 —

如上，未初始化的指针，栈上给其分配内存时，没有初始化的话，它存的值，也就是它指向的地址的值，取决于栈上那块位置的值；如上，前面的函数mmmm()调用完后，栈上了还留有脏数据，新的函数f00() 创建的野指针的值，变成了栈上的脏值，它是不确定的，也就导致野指针指向了不确定的地址，解引用这个指针，极有可能访问到非法地址，导致程序崩溃。

野指针的成因

未初始化的指针

指针变量声明后若不初始化，它的值是栈上的垃圾值——上一个函数留在那里的位模式。编译器不会报错（C 允许"读未初始化变量"只是未定义行为），运行时也不会报错，只有解引用的那一刻才摊牌。

#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int *p = malloc(sizeof(int));   // 申请堆内存
    *p = 42;
    printf("释放前: *p = %d, p = %p\n", *p, (void *)p);

    free(p);                        // 释放，但 p 还留着旧地址
    // p 现在是悬垂指针！

    printf("释放后: p = %p（地址没变，但已失效）\n", (void *)p);
    printf("*p = %d\n", *p);        // UB：读已释放内存

    p = NULL;   // ← 正确做法：释放后置空，避免悬垂
    return 0;
}

:~$ ./a.out
释放前: *p = 42, p = 0x6180834242a0
释放后: p = 0x6180834242a0（地址没变，但已失效）
*p = 403190820

free(p) 只释放了内存，没有改变 p 里存的地址值。所以 p 还指着那块旧地方，但那地方已经不属于你了。

#include <stdio.h>

int *get_ptr(void) {
    int x = 42;
    printf("局部变量x的地址:%p\n",&x);
    return &x;// 返回局部变量地址
}                        // ← 函数返回，x 的栈空间被"释放"

int main(void) {
    int *p = get_ptr(); // p 拿到的是已经失效的栈地址 → 悬垂指针
    printf("p 的值（旧地址）: %p\n", (void *)p);

    // 此时 x 的栈空间可能已被覆盖
    printf("*p = %d\n", *p);   // UB：可能读到 42，也可能读到垃圾，也可能崩

    return 0;
}
